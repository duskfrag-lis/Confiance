# Confiance — Frontend

SPA en Angular para los 4 roles de Confiance (visitante, cliente, prestador, administrador).

Instrucciones completas de puesta en marcha: ver el README en la raíz del monorepo.

## Comandos

- `ng serve` — desarrollo, http://localhost:4200
- `ng build` — build de producción
- `ng test` — pruebas unitarias (Vitest)
